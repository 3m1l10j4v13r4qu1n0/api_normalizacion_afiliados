# Definition of Ready (DoR)

Una Historia de Usuario no puede moverse a la columna "En desarrollo" si no cumple:

- [ ] Tiene el formato estándar (Como... quiero... para...).
- [ ] Tiene Criterios de Aceptación en formato Gherkin (Dado/Cuando/Entonces).
- [ ] Tiene al menos 2 ejemplos en Specification by Example.
- [ ] Tiene definidos los casos de prueba TDD (positivo y negativo/borde).
- [ ] Tiene especificado el/los endpoint/s de API a implementar.
- [ ] Tiene identificadas las entidades de datos y reglas de negocio que involucra.
- [ ] El backend ha revisado los archivos `.md` específicos de la HU y no tiene dudas bloqueantes.
