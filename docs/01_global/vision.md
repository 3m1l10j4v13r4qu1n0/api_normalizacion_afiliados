# Visión del Proyecto

Modernizar el proceso de normalización, validación y gestión de los datos de afiliados de un sindicato, eliminando la dependencia de procesos manuales y planillas dispersas que generan inconsistencias y registros duplicados.

Se desarrolla una API REST intermediaria entre las fuentes externas (importación manual, Google Sheets y scripts clientes) y los sistemas de consulta, garantizando la calidad de la información mediante validación, normalización y persistencia centralizada. El objetivo es reducir los errores de formato, los duplicados y las demoras en la sincronización, ofreciendo una capa de datos confiable y consistente para el usuario administrativo y los sistemas que consumen la API.
