Historia de Usuario N°6
**Como** Sistema,
**quiero** marcar en Google Sheets las filas que presentaron errores de validación,
**para** que el usuario identifique visualmente los registros problemáticos.

Tarjeta
Después de una importación, las filas con errores deben quedar marcadas en la hoja (fondo rojo) de forma masiva, sin interrumpir el proceso de importación ni modificar los datos originales.

Criterios de Aceptación
- Dado que un registro tiene errores de validación, cuando finaliza la importación, entonces su fila se marca en la hoja (fondo rojo).
- Dado que existen varias filas con errores, cuando se marcan, entonces se realiza una actualización masiva para optimizar rendimiento.
- Dado un registro válido, cuando se marcan errores, entonces su fila no se altera.
- Dado que se marcan errores en la hoja, cuando ocurre, entonces no se interrumpe el proceso de importación.

Specification by Example
- Fila con error = marcada en rojo
- Fila válida = sin cambios
- Varias filas con error = actualización masiva

Acceptance TDD
- Probar marcación de filas con errores
- Verificar actualización masiva
- Verificar que no se alteran filas válidas
