Historia de Usuario N°8
**Como** Usuario Administrativo,
**quiero** generar una tabla de afiliados en Google Sheets,
**para** visualizar la información relevante ordenada y con la edad calculada.

Tarjeta
El sistema debe exportar los afiliados a una hoja de Google Sheets: si la hoja no existe, la crea; si existe, la actualiza con los datos actuales. La tabla muestra nombre y apellido concatenados, la edad calculada dinámicamente y solo datos relevantes, ordenados alfabéticamente.

Criterios de Aceptación
- Dado el listado de afiliados activos, cuando se genera la tabla, entonces los afiliados se ordenan alfabéticamente por nombre y apellido.
- Dado un afiliado, cuando se muestra en la tabla, entonces se concatena nombre y apellido en una única columna y se calcula la edad dinámicamente.
- Dado que la hoja existe, cuando se regenera la tabla, entonces se sobrescribe con el estado actual de la base de datos sin duplicados.
- Dado que la hoja no existe, cuando se genera la tabla, entonces el sistema la crea.
- Dado que no hay afiliados activos, cuando se genera la tabla, entonces el sistema informa que no hay datos para exportar.

Specification by Example
- Hoja existente = tabla actualizada (sobrescrita)
- Hoja inexistente = se crea la hoja
- Afiliado = nombre y apellido concatenados + edad calculada
