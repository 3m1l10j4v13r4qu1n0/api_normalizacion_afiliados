Historia de Usuario N°5
**Como** Usuario Administrativo,
**quiero** importar afiliados desde Google Sheets,
**para** procesar los datos sin carga manual.

Tarjeta
La carga de datos desde Google Sheets debe automatizarse: el sistema lee la hoja, mapea los encabezados, valida y normaliza los registros, y guarda solo los válidos registrando los errores.

Criterios de Aceptación
- Dado que la hoja contiene encabezados y filas de datos, cuando se importa, entonces el sistema mapea los encabezados a variables internas y cada fila conserva su `row_number`.
- Dado que una fila tiene datos inválidos, cuando se procesa, entonces el sistema registra el error y continúa con las siguientes filas.
- Dado un registro con DNI duplicado, cuando se procesa, entonces se registra el error de duplicado y se descarta.
- Dado que no hay filas vacías, cuando se procesa, entonces no se generan registros vacíos.
- Dado que finaliza la importación, cuando se completa, entonces el sistema devuelve el resumen con procesados, válidos y errores.

Specification by Example
- Hoja con 10 filas (8 válidas, 2 con error) = 8 válidos, 2 errores
- Fila con DNI duplicado = rechazada con error
- Encabezados en otro idioma = mapeados a variables internas
