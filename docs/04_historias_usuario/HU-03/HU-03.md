Historia de Usuario N°3
**Como** Usuario Administrativo,
**quiero** consultar los afiliados (listado o por ID),
**para** obtener su información almacenada.

Tarjeta
El listado y la consulta individual de afiliados deben devolver la información de manera confiable y rápida. Si el afiliado no existe, se debe informar claramente.

Criterios de Aceptación
- Dado que se solicita el listado de afiliados, cuando se consulta, entonces el sistema devuelve todos los afiliados almacenados en formato JSON.
- Dado que se consulta un afiliado por su ID existente, cuando se realiza la búsqueda, entonces el sistema devuelve los datos del afiliado.
- Dado que se consulta un afiliado por un ID inexistente, cuando se realiza la búsqueda, entonces el sistema informa un error 404.
- Dado un afiliado dado de baja, cuando se consulta, entonces no aparece en los listados de afiliados activos.

Specification by Example
- ID existente = afiliado devuelto
- ID inexistente = error 404

Acceptance TDD
- Probar listado de afiliados
- Verificar consulta por ID existente
- Verificar error 404 para ID inexistente
